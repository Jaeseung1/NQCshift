# 교대온 간단

CSV로 불러온 내 근무표를 오늘·내일·한 달로 보는 웹 앱입니다. 서버·로그인 없이 그 기기 브라우저에만 저장합니다.

- 탭: 홈(오늘·내일·앞으로 7일), 근무표(달력), 설정(CSV 불러오기)
- 근무: 일근 08:30–17:30, 야근 17:30–다음 날 08:30(조근 날 아침까지 이어지는 한 근무). 날짜는 한국 기준, 시각은 기기 시간대
- 색·모양: 통합관제실 근무표(모카 톤, 근무 색 칩)와 같게, 어두운 화면 지원

## 아이폰에서 쓰기
1. 이 레포를 GitHub Pages로 공개: 레포 **Settings → Pages → Deploy from a branch**, Branch `main`, 폴더 `/ (root)` → Save. 1~2분 뒤 주소가 나온다.
2. 아이폰 Safari로 그 주소를 열고 공유 버튼 → **홈 화면에 추가**.
3. 앱의 설정 → 이번 달/다음 달 → **CSV 파일 고르기**(또는 엑셀에서 복사해 붙여 넣기).

## CSV 모양
1. 날짜 줄(1, 2, 3…) 아래 이름과 근무가 있는 표. 여러 사람이면 내 줄을 고른다(통합관제실 근무표 엑셀을 CSV로 저장한 모양).
2. `날짜,근무` 두 칸. 날짜는 `1`, `11/1`, `2026-11-01` 모두 된다.
3. 근무만 한 줄(1일부터 차례로).

근무 글: `일` `야` `조` `O`(비번·휴·휴무도 같음) `휴가` `대일`. 그 밖의 글(예: 교육)은 그대로 보여 준다. UTF-8과 윈도우 엑셀 CSV(CP949) 모두 읽는다.
